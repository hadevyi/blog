## 왜 이 조합을 골랐는가

이번 사이트는 로그인이나 서버 기능보다 **콘텐츠 구조**, **검색성**, **유지보수성**이 더 중요했습니다.

그래서 아래 조건을 만족하는 스택이 필요했습니다.

- GitHub Pages에서 무리 없이 배포 가능할 것
- 이력서, 포트폴리오, 경험, 블로그를 각각 독립 URL로 가질 것
- 나중에 `GA`와 `Search Console`을 붙이기 쉬울 것

## 이번에 적용한 기본 구조

- `/`
- `/resume/`
- `/portfolio/`
- `/experience/`
- `/blog/`
- `/blog/[slug]/`
- `/portfolio/[slug]/`
- `/experience/[slug]/`
